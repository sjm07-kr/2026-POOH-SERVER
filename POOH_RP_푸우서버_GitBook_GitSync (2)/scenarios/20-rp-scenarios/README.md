# 20. 상황별 RP 가이드

진행 중인 상황에 맞는 페이지를 열어 적용 조항을 확인하세요. 아래 예시는 기존 푸우서버 조항을 실제 플레이 흐름에 적용한 안내입니다.

| 상황 | 읽을 페이지 |
|---|---|
| 경찰 정차 지시, 차량 추격, 접속 끊김 | [21. 검문·추격·도주 RP](21-pursuit-rp.md) |
| 납치, 감금, 인질과 협상 | [22. 납치·인질·협상 RP](22-hostage-rp.md) |
| 절도, 차량 절도, 강도 | [23. 절도·강도 RP](23-robbery-rp.md) |
| 팩션 간 갈등, 전쟁 RP, 공용자산 | [24. 팩션 분쟁 RP](24-faction-conflict-rp.md) |

특정 콘텐츠의 참여 인원, 장비, 시작·종료 조건은 해당 콘텐츠의 최신 공식 공지를 확인하세요. 모든 상황에 [08. RP 기본 규칙](../../community/08-rp-basics.md)과 [09. 뉴비 보호와 보호구역](../../community/09-new-player-protection.md)가 함께 적용됩니다.
